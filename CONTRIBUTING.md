# Contribution Guidelines

Thank you for your interest in contributing to **POPCORN KING Ghana**!

## Development Workflow

1. Fork the repo and create your feature branch:
   ```bash
   git checkout -b feature/amazing-feature
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Verify code passes typecheck and linting:
   ```bash
   npm run lint
   npm run build
   ```
5. Commit your changes and open a Pull Request with a clear summary of your updates.
